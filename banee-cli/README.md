# بانِي CLI

بانِي من الـ terminal. نفس محرك تطبيق بانِي (`www/index.html`) يعمل في متصفح خفي، فتحصل على نفس الجودة: المحلل، المخطط، الشاشات، الفحص، ووكيل الإصلاح.

## التثبيت (أمر واحد)

```bash
curl -fsSL https://skfk86.github.io/banee/install.sh | bash
```

ثم داخل أي مشروع:

```bash
banee
```

أول مرة يطلب مفتاح Gemini (مجاني من [aistudio.google.com/apikey](https://aistudio.google.com/apikey))، يتحقق منه ويحفظه، ولا يسأل بعدها.
يعمل على Linux وmacOS وTermux، ويحتاج Node.js 18 أو أحدث.

| الأمر | المعنى |
|---|---|
| `banee update` | تحديث لآخر إصدار |
| `banee key` | تغيير المفتاح |
| `banee -v` | رقم الإصدار |

> للتطوير من داخل المستودع: `cd banee-cli && npm install && npm run sync-engine && npm link`

## الأوامر

### `banee` — محادثة مباشرة (مثل Claude Code)

```bash
cd ~/Projects/apps/wateen
banee
❯ غيّر لون الزر الرئيسي للأخضر
❯ ماذا عدّلت؟
❯ أضف صفحة إعدادات فيها وضع ليلي
```

محادثة مستمرة داخل المشروع: يتذكر ما قلته وما عدّله، يجيب الأسئلة مباشرة، ويعدّل ويفحص عند الطلب. ما تكتبه وهو يعمل لا يضيع، بل يُنفَّذ بعده.

| داخل المحادثة | المعنى |
|---|---|
| `/new فكرة` | بناء تطبيق كامل جديد |
| `/check [ملف]` | فحص أخطاء الصياغة |
| `/clear` | محادثة جديدة |
| `/exit` | خروج |

### `banee new` — بناء تطبيق كامل

```bash
banee new "تطبيق حجز مواعيد لعيادة أسنان في الخرطوم"
banee new --kit delivery --out ~/Projects/apps/my-delivery
```

يعرض المخطط في الـ terminal ويطلب موافقتك، ثم يبني ويخرج مشروع أندرويد Capacitor كاملاً (نفس ملفات زر «مشروع أندرويد» في التطبيق: `www/index.html`، `capacitor.config.json`، سير عمل GitHub لبناء APK، الأيقونات وشاشة البداية).

| الخيار | المعنى |
|---|---|
| `--out` | مجلد الإخراج (الافتراضي اسم التطبيق بالحروف اللاتينية) |
| `--name` | اسم التطبيق |
| `--id` | معرّف الحزمة، مثل `com.alloush.clinic` |
| `--admob` | معرّف تطبيق AdMob (الافتراضي التجريبي من Google) |
| `--kit` | نظام جاهز: `delivery` · `store` · `booking` · `edu` |
| `--yes` | موافقة تلقائية على المخطط |

### `banee edit` — وكيل تعديل المشروع الحالي

```bash
cd ~/Projects/apps/wateen
banee edit "أضف زر وضع ليلي في الإعدادات"
```

يقرأ المشروع، يعدّل بأقل تغيير، يفحص صياغة JS بعد كل تعديل، ويصلح أخطاءه. يطلب تأكيدك قبل الأوامر الحساسة (`rm`، `git push`...)، ولا يكتب خارج مجلد المشروع. اعمل داخل git لتتراجع بسهولة.

### `banee check` — فحص سريع بلا ذكاء اصطناعي

```bash
banee check www/index.html
```

## ملاحظات

- يعمل بمفتاح Gemini الخاص بالمستخدم مباشرة (لا يمر بخادم بانِي)، مثل الخطة المدفوعة.
- قاعدة البيانات في المشروع الناتج تجريبية محلية؛ اربطه بمشروع Firebase الخاص بصاحب التطبيق قبل النشر.
- `banee new` يستغرق عادة بين ١٥ و٦٠ دقيقة حسب حجم التطبيق.
