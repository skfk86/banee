# قادة النيل (Qadat Al-Nil)

لعبة استراتيجية حربية في الوقت الحقيقي (RTS) للموبايل، بأسلوب ألعاب بناء القاعدة والجيوش الكلاسيكية، لكن بهوية أصلية بالكامل.

## البرومت المرجعي (استخدمه لأي تطوير جديد)

> أنت مطوّر ألعاب محترف تعمل على "قادة النيل"، لعبة RTS ثلاثية الأبعاد بمنظور علوي مائل،
> مبنية بـ Godot 4.7 و GDScript، تستهدف هواتف Android متوسطة الأداء في السودان والعالم العربي.
> اللعبة أصلية: لا تستخدم أي اسم أو شعار أو تصميم أو صوت أو خريطة من ألعاب تجارية أخرى.
> الواجهة عربية بالكامل (RTL)، والتحكم باللمس أولاً (سحب، تقريب بإصبعين، ضغط، ضغطتين).
> حافظ على الأداء: الهدف 60 إطاراً على الأجهزة المتوسطة، ومحرك العرض Mobile.
> كل رقم توازن (صحة، ضرر، تكلفة، زمن) يعيش في `scripts/data.gd` فقط.
> اكتب كوداً واضحاً بتعليقات عربية قصيرة، واختبر بـ `godot --headless --quit-after` قبل التسليم.

## هيكل المشروع

| الملف | الدور |
|---|---|
| `scripts/data.gd` | (Autoload باسم Data) كل أرقام التوازن: الوحدات، المباني، الأبحاث، الصعوبات |
| `scripts/game.gd` | المحاكاة كاملة: الحركة، القتال، الاقتصاد، الذكاء الاصطناعي، الكاميرا، اللمس |
| `scripts/entity.gd` | كائن موحد للوحدة والمبنى (حالة + مراجع المجسم) |
| `scripts/models.gd` | بناء المجسمات ثلاثية الأبعاد إجرائياً (بدون ملفات خارجية) |
| `scripts/fx.gd` | الانفجارات، الدخان، المقذوفات، آثار الحريق |
| `scripts/hud.gd` | الواجهة: الشريط العلوي، لوحة الأوامر، القوائم، الأيقونات المصوّرة من المجسمات |
| `scripts/minimap.gd` | الخريطة المصغرة |
| `docs/GDD.md` | وثيقة تصميم اللعبة والخطة المستقبلية |

## أوامر مفيدة

```bash
# فحص الأخطاء بدون نافذة
godot --headless --path . --quit-after 120
# تشغيل اللعبة
godot --path .
```

## قواعد

- الإحداثيات: المحاكاة على مستوى XZ عبر `Vector2 p` (x = X و y = Z)، والخريطة 240×240 متر.
- الفريق 0 هو اللاعب (أخضر)، والفريق 1 هو العدو (أحمر).
- لا تضف أصولاً بحقوق محفوظة. المسموح: مجسمات إجرائية، أو أصول برخصة CC0 (مثل Kenney) مع ذكر المصدر في `docs/CREDITS.md`.

## الحالة الحالية (النسخة 0.2)

- محرك العرض: `gl_compatibility` لأن الجهاز المستهدف Redmi A3x (اقتصادي). لا تستخدم Decal أو أضواء OmniLight أو جسيمات كثيرة.
- الأصوات مولّدة بالكود في `scripts/sfx.gd` (Autoload باسم Sfx): طبقات متعددة ونسخ عشوائية لكل صوت، حافلتا SFX (صدى + ضاغط) و Music، ومحدّد على Master.
  موسيقى أصلية على مقام الحجاز تُولَّد في خيط منفصل (`Sfx.music(on, battle)`)، ورياح صحراوية أثناء المعركة.
  أي ملف `res://sounds/<الاسم>.ogg` يستبدل الصوت المولّد تلقائياً.
- الرسومات: ACES + توهج (Glow) + تصحيح ألوان، ضوء ملء سماوي، أرض بخريطة نتوءات وطبقة تفاصيل، اهتزاز الكاميرا مع الانفجارات، ومقذوفات بألوان HDR.
- المرحلة التعليمية في `game.gd` (دالة `_tutorial`)، وشريطها في `hud.gd`.
- المجسمات ما زالت إجرائية في `models.gd`. **الأولوية التالية:** استبدالها بأصول CC0 (Kenney / Quaternius / Poly Haven) مع الحفاظ على لون الفريق، وتسجيل المصادر في `docs/CREDITS.md`.

## الاختبار

```bash
godot --headless --path . --quit-after 60            # فحص أخطاء السكربتات
godot --headless --path . -s tests/sim_test.gd       # مباراة آلية كاملة
```

## بناء APK

إعداد التصدير في `export_presets.cfg` (اسم الحزمة com.alloush.qadatalnil). يحتاج Android SDK في إعدادات المحرر:
Editor > Editor Settings > Export > Android. للنشر في Google Play يجب إنشاء مفتاح Release خاص وحفظه بأمان.
